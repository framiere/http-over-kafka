Send a request. Watch Kafka keep it.

Each button sends a real HTTP request to the gateway, as the checkout application would. The service answers as usual. In the Kafka panel, every record Kafka commits shows up as it lands.

From a terminal: TOKEN=$(curl -s http://localhost:8090/token) gets a caller token from the playground's dev identity provider, valid 1 h. It signs with the insecure dev key committed in the repo.
